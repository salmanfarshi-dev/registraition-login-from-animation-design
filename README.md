# Auth App (React + Vite + Tailwind CSS)

    npm install
    npm run dev      # open the URL shown (usually http://localhost:5173)

Customize:
- Colors: tailwind.config.js -> colors (brand, navy, ink)
- Panel text/spheres: src/components/Art.jsx
- Form fields & validation: src/components/RegisterForm.jsx / LoginForm.jsx
- API calls: look for the TODO comments
- Animation speed: change duration-[950ms] in Art.jsx
